# 스타듀 똥밸리

스타듀밸리 스타일의 농사 게임입니다. 단, 이 마을에서는 **무엇을 심든 똥이 자랍니다.**
파스닙도, 딸기도, 호박도, 멜론도 전부 똥으로 열려요.

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 플레이 방법

1. 괭이로 풀밭을 갈아 밭을 만든다.
2. 씨앗을 고르고 밭에 심는다.
3. 물뿌리개로 물을 준다. 물을 준 날 밤에만 똥이 자란다.
4. 얼굴이 생기고 파리가 꼬이면 다 자란 똥. 행동 키나 낫으로 수확한다.
5. 똥을 들고 출하함에 넣으면 밤사이 돈이 들어온다. 뿌지직 상회에서 바로 팔 수도 있다.
6. 집 문 앞에서 잠을 자면 하루가 끝나고 자동 저장된다. 새벽 2시가 되면 쓰러진다.

## 조작

| 동작 | 키보드 / 마우스 |
| --- | --- |
| 이동 | `WASD` / 방향키 |
| 도구 쓰기 | `C` / `스페이스` / 왼쪽 클릭 (꾹 누르면 반복) |
| 행동 (수확·출하·상점·잠) | `X` / `F` / 오른쪽 클릭 |
| 핫바 선택 | `1`~`=`, 마우스 휠, `Q` / `R` |
| 가방·도감·설정 | `E` / `I` / `Esc` |
| 소리 켜기/끄기 | `M` |

휴대폰에서는 화면 아래 방향 버튼과 `도구` / `행동` 버튼으로 조작합니다.

## 그 밖의 기능

- 비 오는 날은 밭에 저절로 물이 듬뿍
- 스프링클러: 매일 아침 상하좌우 4칸에 물주기
- 에너지 쿠키, 물뿌리개 업그레이드
- 사계절 풍경, 밤 조명, 비·눈 효과
- 수확할 때 나는 "뿌지직" 효과음 (WebAudio로 직접 합성)

## 파일 구성

```
index.html      화면 뼈대
style.css       나무판·양피지 UI
js/data.js      작물(똥)과 아이템 정의
js/sprites.js   똥·도구·아이콘 픽셀 아트 (코드로 생성)
js/tiles.js     지형·나무·건물 픽셀 아트
js/audio.js     효과음 합성
js/world.js     농장 지도, 게임 상태, 저장
js/render.js    캔버스 렌더링
js/ui.js        HUD, 핫바, 가방, 상점, 정산 화면
js/game.js      입력, 농사, 하루 순환, 메인 루프
```

이미지 파일 없이 모든 그래픽을 코드로 그립니다. 저장 데이터는 브라우저 `localStorage`에 남습니다.
