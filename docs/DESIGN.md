# 스타듀 똥밸리 v2 — 마스터 설계서

목표: **스타듀밸리와 같은 그래픽 스타일, 같은 모션, 같은 기능**을 가진 게임. 단 하나의 차이:
**모든 작물과 채집 식물은 똥이다.** (물고기, 광물, 달걀·우유 같은 동물 생산물, 나무는 똥이 아니다.)

이 문서는 모든 작업자가 따르는 기준이다. 엔진 API의 정확한 사용법은 `docs/ARCHITECTURE.md`(코어 작업자가 작성)를 본다.

---

## 0. 절대 규칙

1. **저작권**: 스타듀밸리의 실제 이미지, 스프라이트, 음악, 캐릭터 이름, 대사, 지명은 절대 복사하지 않는다.
   모든 픽셀 아트는 코드로 직접 그린 오리지널이다. "스타일, 크기, 비율, 애니메이션 타이밍, UI 배치, 게임 규칙·수치"는 원작과 같게 맞춘다(게임 규칙과 수치는 저작권 대상이 아님).
   NPC·가게·지명은 오리지널 한국어 이름(똥 말장난 환영)을 쓴다. 예: 피에르 → `뿌직이 아저씨`, 가게 → `뿌지직 상회`.
2. **기술**: 바닐라 JS, ES 모듈 금지(일반 `<script>`), 빌드 없이 `index.html`을 file://로 열어 동작. 외부 이미지 파일 없음(모든 그래픽은 캔버스로 생성). 외부 라이브러리 없음.
3. **단일 파일 배포**: `python3 tools/bundle.py`가 모든 CSS/JS/폰트를 인라인한 `dist/stardew-ddong.html`(아티팩트용: doctype/html/head/body 태그 없음)을 만든다. 따라서 JS 안에 `</script` 문자열 금지, 런타임 fetch 금지.
4. **한국어 UI**. 모든 텍스트는 한국어.
5. **견고함**: 모듈 하나가 에러를 내도 게임 루프가 멈추면 안 된다(코어가 훅 호출을 try/catch로 감싼다).
6. **저장**: 잠을 잘 때 `localStorage`에 자동 저장(모든 접근은 try/catch). 모듈 상태도 저장/복원된다.

## 1. 그래픽 기준 (스타듀 스타일)

### 1.1 배율과 크기
- 기본 타일 16×16 px. 기본 화면 배율 4배(타일 64 CSS px). 화면 높이가 작으면 3배/2배로 자동 축소, 설정에서 줌 조절(2~5).
- 정수 배율, `imageSmoothingEnabled=false`, 카메라를 디바이스 픽셀에 정렬 → 픽셀이 또렷해야 한다.
- 스프라이트 크기(원작 비율):
  - 농부: 프레임 16×32 (머리가 큰 SD 비율: 머리 약 12px 폭, 몸통 짧음, 다리 짧음).
  - 작물: 16×32 (다 자라면 타일 위로 솟는다). 거대 작물 48×64.
  - 나무(참나무·단풍나무·소나무): 48×96 수준, 줄기 1타일, 성장 단계 5(씨앗→새싹→묘목→어린나무→다 자란 나무).
  - 농가: 약 9×6 타일 + 지붕. 출하함 2×1. 다른 건물(헛간, 닭장, 가게)도 원작 비율.
  - 덤불, 큰 바위, 큰 그루터기: 2×2 타일.
- 모든 오브젝트 아래 반투명 타원 그림자(rgba(0,0,0,.25~.3)).

### 1.2 팔레트와 질감
- 원작처럼 채도 높고 따뜻한 색. 외곽선은 검정이 아니라 **채움색의 어두운 톤**(색상 유지, 명도↓).
- 픽셀 셰이딩: 위쪽 왼쪽이 밝고 아래 오른쪽이 어두운 3~4단계 명암, 디더링 최소화.
- 땅: 계절별 잔디(봄 연두, 여름 진초록, 가을 황갈색, 겨울 눈). 잔디 타일은 여러 변형 + 풀포기. 
- 괭이로 간 흙은 **자동 타일링**(이웃 흙과 이어지는 테두리 47/16-타일 방식), 물 준 흙은 짙은 색.
- 물: 반짝이는 하이라이트가 천천히 흐르고, 물가에 밝은 테두리와 거품.
- 절벽/단차: 흙색 절벽면 + 윗면 잔디 테두리(원작 지형처럼).

### 1.3 똥 작물 아트
- 모든 작물 = 똥. 단계: 씨앗 → 새싹(초록 떡잎, 원작 같은 작은 싹) → 잎 달린 작은 똥 → 자라는 똥(줄기·잎 + 똥 몸통이 커짐) → 다 자란 똥(작물별 고유 색·모양, 귀여운 얼굴, 파리, 냄새 줄기).
- 작물별로 실루엣이 달라야 한다: 둥근 똥(감자·호박), 길쭉하게 솟은 똥(옥수수·해바라기), 덩굴 지지대 똥(그린빈·홉·포도: 지나갈 수 없는 지지대), 꽃잎 달린 똥(튤립·블루재즈·양귀비·요정장미·해바라기), 줄무늬(멜론), 씨 박힌(딸기), 알갱이(옥수수), 반짝임(고대똥, 무지개똥).
- 수확 아이콘(16×16)은 똥 단독 모습.
- 거대 작물(콜리플라워·멜론·호박 똥): 3×3 거대 똥, 도끼로 쪼개면 15~21개.

### 1.4 UI (원작 배치와 같은 형태, 오리지널 그림)
- 전체 UI는 **픽셀 폰트**(Galmuri11/Galmuri9, OFL 라이선스 — `assets/fonts/`에 포함, 번들 때 data URI로 인라인)와 **나무색 9-slice 프레임**(진한 갈색 테두리, 주황빛 나무, 안쪽 밝은 테두리). UI도 캔버스 또는 픽셀 스타일 HTML로, 둥근 모서리 대신 계단식 픽셀 모서리.
- 오른쪽 위 **시계**: 날짜 상자(“월. 1” 형식 → `월 1일`), 반원형 해/달 다이얼과 진행 바늘, 날씨 아이콘, 계절 아이콘, 시간 텍스트, 그 아래 **금화 카운터**(숫자가 굴러가는 애니메이션).
- 오른쪽 아래 **기력 바**(세로, `E` 라벨, 초록→노랑→빨강), 광산·전투 중에는 옆에 **체력 바**.
- 아래 중앙 **툴바** 12칸(선택 칸 빨간 테두리, 개수 숫자, 품질 별, 물뿌리개 물 게이지). `Tab`/`Ctrl+Tab`으로 인벤토리 줄 순환.
- **인벤토리 메뉴**(`E`/`Esc`): 큰 나무 프레임 + 위쪽 탭 아이콘: 가방 · 스킬 · 관계 · 지도 · 제작 · 수집 · 설정 · 나가기. 가방 탭: 12×3 그리드, 왼쪽 아래 농부 미리보기, 이름·금화, 쓰레기통.
- **툴팁**: 아이템 위에 마우스 → 이름, 분류(색 라벨: 채소/과일/꽃/채집/물고기/광물/요리/장인 제품…), 설명, 기력·체력 회복량, 가격.
- **대화창**: 화면 아래 큰 상자, 오른쪽에 초상화와 이름표, 타자기처럼 한 글자씩 출력, 클릭하면 다음 페이지, 선택지.
- **HUD 메시지**: 왼쪽 아래 아이콘 + 텍스트 상자(“파스닙똥 +1” 같은 획득 알림은 같은 아이템이면 수량 누적).
- **상점 메뉴**: 원작처럼 왼쪽에 주인 초상화+인사말, 가운데 판매 목록(아이콘·이름·가격), 아래에 내 가방(팔기), 수량 선택.
- **하루 정산**: 잠들면 화면이 어두워지고 분류별(농사·채집·낚시·광산·기타) 수익 표, 총액, 레벨업 시 레벨업 화면(새 제작법 안내).
- 마우스 커서: 픽셀 장갑/화살표 커서, 도구 범위 하이라이트(차지 시 사각형 범위).

## 5. 품질 기준과 테스트

- `tests/smoke.js`: Playwright(`/opt/node22/lib/node_modules/playwright`)로 file:// 로드, 새 게임, 이동·농사·수면 루프, 콘솔 에러 0, 스크린샷 저장. 각 모듈은 `tests/<module>.js` 테스트를 추가한다.
- 디버그 API `window.DBG`: 아이템 지급, 시간/날짜 설정, 워프, 돈, 스킬 레벨, 즉시 성장 등 — 테스트와 개발용.
- 스크린샷은 `tests/out/`(gitignore)에 저장.
- 성능: 4배 줌 1080p에서 60fps. 매 프레임 할당 최소화, 스프라이트는 미리 렌더링해 캐시.
